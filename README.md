# Drift 🌙

A quiet space to capture the moments that pass too quickly.

Write down your thoughts, record the sounds around you, and preserve the small details of your day before they disappear.

Drift is not about documenting what happened — it’s about remembering how it felt.

> Write less. Remember more.

---

## ✨ Features

- 🗺️ Interactive map interface
- 📍 Create notes tied to real-world locations
- 💭 Clean, distraction-free writing experience
- 🌙 Minimal dark-first design
- 📱 Native iOS app built entirely with SwiftUI
- ⚡ Smooth animations and modern UI
- 🔒 Privacy-focused (your memories stay yours)

## Getting Started

Clone the repository

```bash
git clone https://github.com/Damoon03/Drift.git
```

Open the project in Xcode.

Install dependencies (if using Swift Package Manager they'll resolve automatically).

Add your own Firebase configuration:

```
GoogleService-Info.plist
```

Build and run.

## Design Philosophy

Most journaling apps organize memories by **time**.

Drift organizes them by **place**.

The goal is to make memories feel physical again—something you can revisit by exploring the map rather than scrolling through an endless list.
